# Runtime Assurance v0.4 Composition Example

This example shows the v0.4.0 Trust Graph Artifacts alignment path:

```text
Trust Graph essay-derived package
-> TSMM authority graph and runtime governance envelope
-> TIS authority boundary
-> TIS evidence bundle
-> TIS evaluation envelope
-> TIS decision receipt
-> TIS registry publication profile
-> TGA provenance extension
```

The example is intentionally compact. It proves the repository boundary: TGA owns the essay-derived package and provenance interpretation, TSMM owns the semantic governance model, and TIS owns the externally validatable artifact contracts.
