# Trace

Use this section when the question is not only what an artifact says, but where it came from and how the claim can be audited.

- [Essay-to-artifact index]({% link essays/index.md %}) — source pressure and artifact families.
- [Decision provenance]({% link docs/decision-provenance.md %}) — provenance carried into runtime decision evidence.
- [Essay-to-TSMM method]({% link docs/essay-to-tsmm-method.md %}) — disciplined translation from narrative pressure to canonical semantics.

Traceability should preserve the distinction between source motivation, semantic authority, implementation artifacts, runtime evidence, and release publication state.
