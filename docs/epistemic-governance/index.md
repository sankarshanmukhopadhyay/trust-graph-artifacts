# Epistemic governance

This learning path converts the governance pressure identified in *The Edge Knows First* into testable controls. It addresses decisions that may be properly authorised and fully receipted, yet remain structurally blind because relevant situated knowledge cannot reach the decision surface before an effect is admitted.

## Assurance boundary

A passing epistemic-adequacy result does not assert complete knowledge or a correct decision. It proves only that the declared discovery, challenge, authority, evidence, expiry, and redress conditions were met for the assessed scope.
