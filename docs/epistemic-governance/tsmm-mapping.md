# TSMM mapping

The package uses the reviewed TSMM v0.23.0 baseline without asserting new canonical entities.

| TGA concept | TSMM representation |
|---|---|
| decision-maker | Actor or Role |
| decision authority | GovernanceAuthority |
| knowledge bearer | Subject or Actor with role relationships |
| epistemic assessment | Assessment and EvidenceBundle |
| knowledge-path rule | Policy |
| proposed action | Effect |
| challenge result | TrustDecision |
| suspension or override | lifecycle state and receipt-bearing Effect |

Candidate concepts are documented separately for possible future TSMM consideration. Promotion requires cross-domain implementation evidence and TSMM governance approval.
