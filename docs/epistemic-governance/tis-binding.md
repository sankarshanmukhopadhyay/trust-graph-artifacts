# TIS binding

TIS remains authoritative for portable schema contracts. The current package profiles existing contract classes rather than adding a TIS schema.

| TGA evidence | TIS contract class |
|---|---|
| epistemic impact assessment | evidence bundle manifest |
| prior-incident result | artifact reference |
| challenge evidence | evidence artifact |
| suspension state | status evidence |
| emergency override | decision receipt |
| reviewer authority | authority boundary |
| implementation claim | conformance declaration |

See `bindings/tis/epistemic-governance-binding.json` for the machine-readable binding.
