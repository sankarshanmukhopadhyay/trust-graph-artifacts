# Epistemic governance TSMM extension candidate

This note records non-normative candidate concepts: `KnowledgeDependency`, `KnowledgeBearer`, `KnowledgePath`, `EpistemicCondition`, `EpistemicChallenge`, `SituatedProximity`, and `DecisionSuspension`.

No concept is proposed for canonical promotion until at least two distinct domains demonstrate stable semantics, adversarial tests, evidence portability, and a material inability to represent the requirement cleanly using current TSMM entities. Promotion requires an explicit TSMM issue, compatibility analysis, governance review, and migration guidance.
