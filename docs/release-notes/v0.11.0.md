# TGA v0.11.0 — Autonomy-Native Institution

## Release theme

Compose mandate, runtime authority, delegation lineage, capability accreditation, contestability, redress, and receipt chains into an institution-level agentic governance model.

## Added

- `artifacts/autonomy-native-institution/artifact.yaml`
- TSMM v0.24.0 / TIS v0.14.1 mapping
- assurance cases for orphan actions, stale authority, capability mismatch, missing contestability, missing redress, and broken receipt chains

## Governance position

This release adds no new delegation primitive. It composes existing TGA patterns under TSMM semantics and TIS portable contracts. Institution-specific legal and policy authority remains external.
