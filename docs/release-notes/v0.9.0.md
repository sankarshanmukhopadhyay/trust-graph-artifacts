# TGA v0.9.0 — Agent Market Participation

## Release theme

Turn agent market entry from platform affiliation into task-class, configuration-bound, revocable capability accreditation.

## Added

- `artifacts/agent-capability-accreditation/artifact.yaml`
- TSMM v0.24.0 / TIS v0.14.1 mapping
- assurance cases for configuration drift, platform self-certification, insufficient capability, scope excess, and revocation

## Governance position

TGA incubates accreditation controls and tests. It does not define a canonical agent capability credential or assurance scale. TSMM remains semantic authority; TIS remains portable-contract authority.
