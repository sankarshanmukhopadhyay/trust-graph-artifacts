# TGA v0.8.0 — Verifiable Trade Corridor Composition

## Release theme

Compose provenance, authority, context, lifecycle, and decision evidence into a cross-border trust-system model derived from *The Coming Trust Repricing in Global Trade*.

## Added

- `artifacts/verifiable-trade-corridor/artifact.yaml`
- TSMM v0.24.0 / TIS v0.14.1 system projection
- explicit composition with the v0.6 provenance-backed reputation and v0.7 context-bound identifier-use controls
- positive and negative assurance cases for issuer authority, shipment binding, registry freshness, and intermediary substitution

## Governance position

This release is a worked system composition, not a trade standard. Jurisdiction-specific customs, certification, finance, insurance, carrier, and registry rules remain external authorities. TGA demonstrates how their claims can be made inspectable through TSMM semantics and TIS artifacts.

## Assurance posture

A consequential trade effect is inadmissible when the relied-upon issuer cannot be resolved, the claim cannot be bound to the governed object, provenance cannot be reconstructed, contextual use is unauthorized, lifecycle state is stale, or an intermediary assertion substitutes for independently verifiable evidence.

## Validation

```bash
make validate
```

Review must verify that the composition does not introduce project-local replacements for TSMM semantics or TIS portable contracts.
