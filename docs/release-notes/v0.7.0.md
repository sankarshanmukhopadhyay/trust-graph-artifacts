# TGA v0.7.0 — Contextual Trust and Correlation Governance

## Release theme

Turn purpose limitation and cross-context correlation into effect-admission controls that can be tested and receipted.

## Added

- `artifacts/context-bound-identifier-use/artifact.yaml`
- TSMM v0.24.0 / TIS v0.14.1 projection map
- positive and negative assurance cases for purpose expansion, linkage amplification, retention, and receiptability

## Governance position

Interoperability and technical correlatability do not create authority to reuse or link an identifier across contexts. Consequential cross-context use requires explicit purpose authority, authorized target context, bounded derived linkage, lifecycle limits, and auditable decision evidence.

## Authority boundary

No new identifier type, credential format, TSMM semantic primitive, or TIS core schema is introduced by this release.

## Validation

```bash
make validate
```

Review must confirm that all externalized authority, evidence, evaluation, and decision artifacts map to TIS v0.14.1 contracts.

## Next release

v0.8.0 will compose the provenance and contextual-trust controls into a cross-border verifiable trade system model.
