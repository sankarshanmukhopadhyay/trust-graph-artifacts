# Trust Graph Artifacts v0.14.0

## User-facing change

This additive release introduces a tested, TGA-owned decision-resolution evidence consumer, applying published **TSMM v0.26.0** semantic invariants to the portable contract family of **TIS v0.16.0**. It enables implementations to distinguish unresolved conditions, admissible basis changes, and unsupported resolution attempts.

The executable path is `scripts/validate_decision_resolution_consumer.py`; representative records and twelve false-resolution mutations are under `validation/tsms/decision-resolution-consumer.json`. The canonical `make validate` gate includes these tests. The coordinating TSMS qualification runner additionally fetches this consumer at an exact commit and validates TIS records against the published JSON Schema.

## Compatibility

All existing TGA v0.13.0 artifact families and the historically versioned TSMS 2026.2 golden path remain unchanged. This release does not silently replace the stack's accepted TSMM v0.25.0 / TIS v0.15.0 component pins. It is a new independently versioned component input for a prospective TSMS 2026.3 qualification.

## Assurance and limitations

Negative tests reject peer-pressure resolution, unsupported evaluation-context transitions, contradictory authority-change flags, missing provenance or evidence, and incomplete decision records. This establishes modeled local consumer behavior, not authentic source authority, cryptographic provenance, historical completeness, runtime authorization, independent interoperability or certification. `observed_at` remains client observation, not competent recording time.

## Governance

TSMM retains canonical semantic authority, TIS portable-schema authority, and TGA implementation authority. New TSMS stack-level compatibility requires its own governed receipt, pinned release commit, evidence, release gate and explicit human acceptance. The previous TGA tag is immutable.

Release evidence: [TGA #29](https://github.com/sankarshanmukhopadhyay/trust-graph-artifacts/issues/29), [PR #30](https://github.com/sankarshanmukhopadhyay/trust-graph-artifacts/pull/30), [TSMM qualification PR #71](https://github.com/qbf-consulting/trust-systems-meta-model/pull/71). This release requires successful main-branch `make validate` and a workflow-published latest tag.
