# v0.3.1 — Runtime Authority Envelope Validation Hardening

## Overview

This release hardens the v0.3.0 authority-envelope work by converting the core claim of *The Authority Gap* into executable validation logic: agent identity is not sufficient for governance; consequential agent action must be bound to current authority, accountable control, scoped mandate, revocation state, decision evidence, and redress.

## Added

- Added `schemas/receipts/authority_envelope_receipt.schema.json`.
- Added `examples/receipts/authority_envelope_receipt.example.json`.
- Added `validation/authority-envelope-test-cases.yaml`.
- Added `validation/pad-test-cases.yaml`.
- Added `validation/revocation-lag-test-cases.yaml`.
- Added `scripts/validate_authority_envelopes.py`.
- Added standalone `scripts/validate_receipts.py`.
- Added `profiles/public-agent-contestability-profile`.
- Added `artifacts/public-agent-contestability-profile`.
- Added `docs/public-agent-contestability.md`.

## Changed

- Updated `scripts/validate_tsmm_native.py` so authority-envelope, PAD, revocation-lag, and receipt validation run inside the repository-wide validation gate.
- Updated `validation/test-matrix.yaml` to mark `PAD-001`, `PAD-002`, `RLG-001`, `RLG-002`, and `authority-envelope-runtime-completeness` as implemented.
- Updated `patterns/runtime-authority-envelope` with authority-registry resolution, revocation cache bounds, decision-receipt binding, and lifecycle consistency for `retired` state.
- Updated source provenance for *The Authority Gap* to the canonical publication date `2026-05-05`.
- Updated README, documentation index, authority-envelope documentation, receipt documentation, PAD documentation, execution-model guidance, source catalog, crosswalk, and provenance map.

## Governance impact

The repository now tests whether consequential agent actions carry a complete authority envelope, whether preserved authority artifacts remain current at execution time, whether revocation lag is measurable, whether fail-open behavior is flagged, and whether public-agent actions preserve contestability and redress.
