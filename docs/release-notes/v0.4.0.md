# v0.4.0 — TSMM v0.21 and TIS v0.10 Runtime Assurance Alignment

Released: 2026-06-30

Version 0.4.0 aligned Trust Graph Artifacts with TSMM v0.21 and TIS v0.10 and established an end-to-end runtime assurance composition path from essay-derived governance pressure to executable artifact contracts.

## Added

- A TIS v0.10 runtime assurance projection binding under `bindings/tis/`.
- TGA, TSMM, and TIS runtime-assurance and portfolio-alignment crosswalks.
- Runtime-assurance composition examples under `examples/composition/runtime-assurance-v0.4/`.
- Six TSMM-native package families covering personhood participation, agent accountability, machine-decision redress, registry gatekeeper risk, proof-first market decisions, and executable trust governance.
- `scripts/validate_tis_alignment.py` and a complete local validation dependency manifest.

## Changed

- Updated the active TSMM binding from TSMM v0.20 to TSMM v0.21.
- Refreshed onboarding, architecture, binding, crosswalk, provenance, and package documentation for the new runtime-assurance boundary.
- Hardened validators for both lean and fully provisioned environments.

## Governance impact

The release makes authority origin, delegation, scope, policy, evidence, status, revocation, effect admission, registry publication, and redress explicit while preserving two critical boundaries:

1. Essays provide provenance and interpretation, not runtime evidence.
2. Registry publication provides discoverability, not authorization.
