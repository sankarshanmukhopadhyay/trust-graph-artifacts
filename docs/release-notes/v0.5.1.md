# TGA v0.5.1 — Cross-Repository Alignment Baseline

## Purpose

This maintenance release re-pins Trust Graph Artifacts to the current authority repositories before the next essay-derived package train begins.

## Authority boundary

- **TSMM v0.24.0** remains the canonical semantic authority for trust-system concepts, stable semantic identifiers, authority topology, delegation, evidence semantics, lifecycle state, and runtime effects.
- **TIS v0.14.1** remains the canonical portable machine-readable contract authority for executable authority, evidence, evaluation, decision, registry, conformance, and assurance artifacts.
- **TGA v0.5.1** remains the governance-pattern incubation and implementation layer. It does not promote essay-derived concepts into canonical semantics or portable schemas by declaration.

## Changes

- Update the machine-readable TGA→TIS binding to TIS v0.14.1.
- Declare TSMM v0.24.0 as the semantic authority used by the binding.
- Update `PROJECT-STATUS.yaml` compatibility baselines and review date.
- Establish the release boundary for the subsequent market-participation, provenance, contextual-trust, and system-composition releases.

## Validation

Required before merge:

```bash
make validate
python3 scripts/validate_tsmm_native.py
python3 scripts/validate_tis_alignment.py
```

## Assurance evidence

The release is acceptable when:

1. all active packages still validate;
2. all binding targets resolve to current TIS paths;
3. TGA makes no canonical-semantic or portable-schema authority claim;
4. dependency versions in status and binding metadata agree;
5. existing package provenance remains intact.
