# v0.5.0 — Delegation governance

v0.5.0 operationalized the Trust Graph delegation essay set through chain-aware, TSMM-native governance artifacts and negative assurance fixtures.

## Added

- `patterns/delegation-lineage-envelope`
- `profiles/delegation-first-governance-profile`
- cross-repository delegation bindings and adoption guidance
- negative assurance fixtures for multi-hop and fan-out delegation

## Controls

The release added explicit controls for originating-principal continuity, parent-hop lineage, immutable transaction and intent binding, monotonic scope attenuation, trust-domain transitions, fan-out convergence, aggregate authority, revocation propagation, interruption, and compensation.

## Authority boundary

The release preserved TSMM as semantic authority and TIS as the portable schema-contract layer. TGA remained the essay-derived governance interpretation and implementation layer.
