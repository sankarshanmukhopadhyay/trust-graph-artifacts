# TGA v0.6.0 — Provenance-Backed Reputation

## Release theme

Move reputation from inference-only trust signals toward provenance-bearing, context-bounded evidence.

## Added

- `artifacts/provenance-backed-reputation/artifact.yaml`
- TSMM v0.24.0 / TIS v0.14.1 projection map
- positive and negative assurance cases
- implementation-facing admission rule and evidence requirements

## Governance position

TGA does not define a canonical reputation credential or a new semantic primitive. The release incubates a reliance pattern using existing TSMM concepts and TIS portable contracts.

## Conformance intent

A system fails this release's assurance posture when a consequential reputation-influenced decision depends on an unresolvable issuer, missing provenance, incompatible context, stale status, or an aggregate score used as a substitute for evidence.

## Validation

```bash
make validate
```

Review must also confirm that all paths in `mappings/tsmm-tis.yaml` remain valid against TSMM v0.24.0 and TIS v0.14.1.

## Next release

v0.7.0 will model purpose limitation and cross-context correlation as effect-admission controls rather than narrative privacy principles.
