# v0.12.1 — Publication and provenance consolidation

v0.12.1 is a documentation, provenance, and release-governance patch. It does not introduce new canonical trust semantics or portable schemas.

## Changed

- Align the README and documentation index with the active repository version and the TSMM v0.24.0 / TIS v0.14.1 authority baseline.
- Add a current release source catalog for the v0.6–v0.11 Trust Graph-derived artifact train.
- Add a current provenance map linking each source essay to its TGA interpretation and executable assurance cases.
- Add an essay → TGA artifact → TSMM semantic → TIS contract crosswalk.
- Rebuild the essay index around the active artifact families and explicit admission rule.
- Add an auditable release-publication ledger separating merge, validation, tag, and GitHub Release states.
- Restore canonical v0.5.0 release notes from signed commit history.
- Add publication validation so version advancement cannot silently omit release notes or publication metadata.

## Authority boundary

- TSMM v0.24.0 remains canonical semantic authority.
- TIS v0.14.1 remains portable-contract authority.
- TGA remains the project-local executable-governance, provenance, composition, and negative-assurance layer.

## Publication status

The repository records the retrospective release publication backlog explicitly. Git tag and GitHub Release publication is a separate publication step from merging release code and documentation.

## Validation

Run:

```bash
make validate
```

The v0.12.1 gate includes publication/provenance consistency checks in addition to the repository-wide assurance suite introduced in v0.12.0.
