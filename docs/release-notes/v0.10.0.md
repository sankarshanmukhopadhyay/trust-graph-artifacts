# TGA v0.10.0 — Issuer Incentive Inversion

## Release theme

Make issuer reliability, correction, revocation, and redress behavior independently legible rather than allowing verification infrastructure to hide institutional error rates.

## Added

- `artifacts/issuer-incentive-inversion/artifact.yaml`
- TSMM v0.24.0 / TIS v0.14.1 mapping
- negative assurance cases for aggregated revocation opacity, private correction gaps, voluntary-pilot generalization, and middleware authority obfuscation

## Governance position

TGA models institutional incentive and accountability pressure. It does not define sector credential standards or impose sectoral mandates. TSMM remains semantic authority; TIS remains portable-contract authority.
