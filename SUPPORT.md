# Support

Use GitHub Issues for reproducible bugs, documentation defects, validation failures, and bounded enhancement proposals affecting Trust Graph Artifacts.

Before opening an issue:

1. run `make validate` on the current `main` branch;
2. identify the affected artifact, profile, pattern, binding, script, or documentation surface;
3. include the relevant validation output and commit/release identifier;
4. distinguish a TGA implementation problem from a TSMM semantic question, a TIS contract question, or an external protocol/institutional authority question.

Security-sensitive reports should follow [`SECURITY.md`](SECURITY.md) and should not be filed publicly when disclosure could increase risk.

The repository does not provide certification, legal interpretation, operational accreditation, or support for authority owned by TSMM, TIS, external protocols, institutions, or legal regimes.
