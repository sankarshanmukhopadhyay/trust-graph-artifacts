# Delegation-First Governance Profile

This profile moves governance upstream from retrospective decision review to the mandate and delegation boundary that define which classes of effects an agent may produce.

## Minimum mandate surface

- scope and prohibited effects;
- effective period and renewal conditions;
- executable constraints and escalation triggers;
- revocation authority and preventive, interruption, and compensation behaviour;
- originating principal and complete principal chain;
- evidence, challenge, and redress routes.

## Adoption decision

Apply this profile to consequential agentic workflows, standing authority, multi-hop delegation, cross-domain execution, or any workflow where effects may persist after revocation.
