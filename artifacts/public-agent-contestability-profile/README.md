# Public Agent Contestability Profile

Source essay: *The Authority Gap* (2026-05-05)

This artifact packages the public-sector contestability hardening added in v0.3.1. It is intentionally scoped to agent-mediated actions that can affect public-service routing, eligibility, review, denial, approval, enforcement, or other administrative consequences.

The artifact requires an authority-envelope receipt, current authority-state check, accountable public controller, human review path, and machine-readable redress route before consequential public effects are finalized.
