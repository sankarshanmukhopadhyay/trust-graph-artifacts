# Agentic Systems Architecture Guide — Adoption and Publication Release

This release turns the architect-facing guide into a practical implementation playbook and a production-ready GitHub Pages documentation surface.

## Adoption improvements

- Nine gated delivery stages with entry criteria, procedures, outputs, tests, evidence, failure modes, and exit gates.
- Copy-ready templates for jobs, effects, mandates, lineage, capabilities, actions, branches, receipts, revocation, remediation, and ADRs.
- Three worked examples covering single-agent, multi-agent, and cross-domain patterns.
- Governance maturity model and consulting work-package structure.
- Component contracts for the role registry, mandate service, lineage verifier, policy decision point, capability broker, enforcement points, evidence store, and revocation service.

## GitHub Pages and Jekyll improvements

- Stable permalinks and hierarchical Just the Docs navigation.
- Mermaid architecture and sequence diagrams.
- Responsive tables, code overflow, and print styling.
- Strict front-matter validation, duplicate-permalink checks, internal-link checks, YAML validation, Jekyll build, and rendered HTML validation.
- Scoped Pages deployment workflow and pull-request documentation gate.

## Compatibility

The guide names only TSMM, TIS, and TGA and does not pin repository versions. Implementations are required to record their adopted revisions in their own architecture baseline.
